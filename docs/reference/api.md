# API Reference

Everything is in one class, imported from `teachable_machine_lite`:

```python
from teachable_machine_lite import TeachableMachineLite
```

The module also has `teachable_machine_lite.RUNTIME`, the name of the TensorFlow Lite runtime in
use: `"ai-edge-litert"`, `"tflite-runtime"` or `"tensorflow"`.

::: teachable_machine_lite.TeachableMachineLite
